4. Database Commands (Prisma)

All database commands run via npm scripts from the project root.

# Generate Prisma client (run after schema changes) npm run db:generate # Run development migrations (creates tables) npm run db:migrate # Seed database with initial data npm run db:seed # Open Prisma Studio (visual database browser) npx prisma studio # Or from packages/database/: cd packages/database && npx prisma studio # Reset database (drops all data, re-runs migrations) cd packages/database && npx prisma migrate reset # Deploy migrations to production cd packages/database && npx prisma migrate deploy # Format Prisma schema cd packages/database && npx prisma format # Validate Prisma schema cd packages/database && npx prisma validate

11. Mobile App — Android

Setup (First Time)

# Navigate to mobile directory cd apps/mobile # Install Flutter dependencies flutter pub get # Check connected devices flutter devices # Check Flutter environment flutter doctor

Run on Android Device (USB)

# Ensure USB debugging is enabled on your phone # Verify device is detected: adb devices # Run app directly on connected device flutter run # Run in release mode on device flutter run --release

Build Android APK

# Debug APK (for development/testing) flutter build apk --debug # Release APK (for distribution) flutter build apk --release # Profile APK (for performance testing) flutter build apk --profile # Install debug APK via USB adb install build/app/outputs/flutter-apk/app-debug.apk # Install release APK via USB adb install build/app/outputs/flutter-apk/app-release.apk # Install (replace existing app) adb install -r build/app/outputs/flutter-apk/app-debug.apk # Launch app on device adb shell am start -n com.example.telnd_mobile/.MainActivity # Uninstall app from device adb uninstall com.example.telnd_mobile

Android Code Generation

# Run build_runner for Riverpod/JSON code generation dart run build_runner build --delete-conflicting-outputs # Watch mode (auto-rebuild on changes) dart run build_runner watch --delete-conflicting-outputs
